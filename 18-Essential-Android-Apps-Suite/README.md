## ⚡ 4. Quick-Start Setup Recommendations

### Step 1: Instant System-Wide Adblocking (Zero Battery, Zero Apps)
1. Open Android **Settings** -> **Network & Internet** (or **Connections**).
2. Tap **Private DNS** -> Select **Private DNS provider hostname**.
3. Enter: `dns.adguard-dns.com` (or your custom `xxxxxx.dns.nextdns.io`).
4. Tap **Save**. *Result: 95% of in-app ads and trackers are instantly blocked with 0% battery impact.*

### Step 2: Instant PC ↔ Android Wireless Bridge
1. Install **LocalSend** on your Windows PC and your Android phone.
2. Connect both to the same Wi-Fi network.
3. Open LocalSend on both devices to instantly share files and folders at full local speeds ($50\text{--}90\text{ MB/s}$) with zero cables.

### Step 3: Zero-Distraction Offline Media & Documents
1. Install **ReadEra** for documents, PDFs, and books (requests 0 internet permissions).
2. Install **Musicolet** for local music playback (requests 0 internet permissions).
3. Install **ZArchiver** for opening ZIP, 7z, and RAR archives.
