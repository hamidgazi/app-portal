💎 Sample 1: Hadith al-Niyyah (حديث النية)
Sahih al-Bukhari #1
إِنَّمَا الأَعْمَالُ بِالنِّيَّاتِ ، وَإِنَّمَا لِكُلِّ امْرِئٍ مَا نَوَى ، فَمَنْ كَانَتْ هِجْرَتُهُ إِلَى دُنْيَا يُصِيبُهَا أَوْ إِلَى امْرَأَةٍ يَنْكِحُهَا ، فَهِجْرَتُهُ إِلَى مَا هَاجَرَ إِلَيْهِ.
تمام اعمال کا دارومدار نیتوں پر ہے، اور ہر شخص کے لیے وہی ہے جس کی اس نے نیت کی۔ پس جس کی ہجرت دنیا حاصل کرنے یا کسی عورت سے نکاح کی غرض سے ہو، تو اس کی ہجرت اسی مقصد کے لیے شمار ہوگی جس کے لیے اس نے ہجرت کی۔
"Actions are judged only by intentions, and every person will get the reward only of what he intended. So whoever emigrated for worldly benefits or for a woman to marry, his emigration was for what he emigrated for."

Musannaf Abd al-Razzaq #5532
إِنَّ الْجُمُعَةَ لَا تَحْبِسُ عَنْ سَفَرٍ ، مَا لَمْ يَحْضُرْ وَقْتُ الصَّلَاةِ.
بے شک جمعہ کا دن سفر سے مانع نہیں ہوتا، جب تک کہ نماز کا وقت داخل نہ ہو جائے۔
"Indeed, Friday does not prevent one from travel, as long as the time for prayer has not arrived."
📜 Sample 3: Dense Mustalah Technical Definition (تعریفِ حدیثِ صحیح)
Nukhbat al-Fikar / Muqaddimah
هُوَ مَا اتَّصَلَ سَنَدُهُ بِنَقْلِ العَدْلِ الضَّابِطِ عَنْ مِثْلِهِ إِلَى مُنْتَهَاهُ مِنْ غَيْرِ شُذُوذٍ وَلَا عِلَّةٍ قَادِحَةٍ.
حدیثِ صحیح وہ حدیث ہے جس کی سند شروع سے لے کر آخر تک متصل ہو، اسے عادل اور کامل الضبط راوی نے اپنے جیسے راوی سے روایت کیا ہو، اور وہ شذوذ اور کسی مخفی علتِ قادحہ سے بالکل پاک ہو۔
"A Sahih Hadith is that whose chain is continuous through the transmission of an upright, highly precise narrator from his peer all the way to its termination, without irregularity or subtle defect."

📋 Ready-to-Paste Production CSS Code

Self-contained font stacks with Google Fonts CDN and bulletproof local system fallbacks.

/* === Antigravity Verified Dual-Font Stacks === */
@import url('https://fonts.googleapis.com/css2?family=Amiri:ital,wght@0,400;0,700;1,400;1,700&family=Gulzar&family=Noto+Nastaliq+Urdu:wght@400..700&family=Noto+Sans+Arabic:wght@400;600;700&family=Readex+Pro:wght@400;500;600;700&display=swap');

:root {
  /* 1. Traditional Nastaliq (Books, Literature & Headings) */
  --font-urdu-nastaliq: 'Noto Nastaliq Urdu', 'Gulzar', 'Jameel Noori Nastaleeq', 'Urdu Typesetting', serif;
  --line-height-nastaliq: 2.3; /* Critical: Nastaliq requires >= 2.2 to prevent dot clipping */

  /* 2. Modern Clean Naskh (Mobile UI, Buttons & Dense Text) */
  --font-urdu-naskh: 'Noto Sans Arabic', 'Almarai', 'Segoe UI', Tahoma, sans-serif;
  --line-height-naskh: 1.6;

  /* 3. Classical Quranic & Hadith Arabic (Flawless Tashkeel/Harakat) */
  --font-arabic-quranic: 'Amiri', 'Scheherazade New', 'Traditional Arabic', serif;
  --line-height-arabic-quranic: 1.9;

  /* 4. Modern Geometric Arabic (Crisp Mobile Display) */
  --font-arabic-modern: 'Readex Pro', 'Noto Sans Arabic', 'IBM Plex Sans Arabic', sans-serif;
  --line-height-arabic-modern: 1.7;
}

/* Sample Classes */
.text-urdu-nastaliq {
  font-family: var(--font-urdu-nastaliq);
  line-height: var(--line-height-nastaliq);
  direction: rtl;
  text-align: right;
}

.text-urdu-naskh {
  font-family: var(--font-urdu-naskh);
  line-height: var(--line-height-naskh);
  direction: rtl;
  text-align: right;
}

.text-arabic-quranic {
  font-family: var(--font-arabic-quranic);
  line-height: var(--line-height-arabic-quranic);
  direction: rtl;
  text-align: right;
}

.text-arabic-modern {
  font-family: var(--font-arabic-modern);
  line-height: var(--line-height-arabic-modern);
  direction: rtl;
  text-align: right;
}
