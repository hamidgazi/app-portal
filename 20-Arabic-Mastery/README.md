## 1. Project Purpose & Executive Overview

This repository houses the permanent offline reference curriculum, textbook-grade chapter manuals, cheatsheets, and the progressive web application **Arabic Mastery 15**.

Designed according to the **Foundations-First Principle (The Madinah Book Law)**, this course systematically bridges the student from absolute zero to confident scriptural literacy without relying on English-filtered or distorted interpretations.

### 🏛️ The Two Core Pillars:
1. **Foundations on Everyday Vocabulary (Chapters 1 to 14)**:
   The mechanics of classical grammar (*demonstratives, definiteness, prepositions, possessive pairs, adjectives, detached/attached pronouns, plurals, 3-letter roots, past/present verb conjugations, and the verbal sentence*) are mastered first using simple, relatable, tangible items (*houses, books, pens, desks, teachers, students, actions*).
2. **The Sacred Grand Capstone (Chapter 15)**:
   Having built automatic grammatical intuition, the student transitions into divine scripture, unlocking **Surah Al-Fatiha**, the **Daily Namaz Azkaar**, and **Short Surahs from Juz 30**.

> [!IMPORTANT]
> **Canonical Sacred Translation Standard**: All Quranic translations across this entire curriculum, study guides, and the interactive web application are strictly sourced from the verified local database of **Kanzul Iman (کنز الایمان)** by Ala Hazrat Imam Ahmad Raza Khan Barelvī (رحمة الله عليه) and **Kanzul Irfan (کنز العرفان)** by Mufti Muhammad Qasim Qadri (originating from `07-Quran-Deep-Analyzer`). Zero external or unverified internet translations are permitted.
