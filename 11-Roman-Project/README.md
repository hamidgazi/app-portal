## 🎯 1. Division Mission & Publishing Standards

The **Roman Urdu Publishing Division** preserves classical Islamic scholarly literature and Hanafi jurisprudence texts in dignified, modern Roman Urdu. Designed specifically for young and international readers who cannot fluently read Urdu Nastaliq or Arabic script, this initiative provides unabridged, scholarly-verified digital editions with zero compromise on scriptural sanctity.

### 🌟 Core Capabilities & Standards
1. **Unified Mobile Web Reader Studio (`index.html`)**:
   - Zero-CORS offline-ready static architecture with in-memory JavaScript dataset (`data/library_catalog.js`).
   - 1-Tap WhatsApp copy & sharing for every individual Mas'ala/Hadith and complete chapters.
   - Live cross-book search across all 3 canonical books with debounced keyword highlighting.
   - AMOLED Pure Black (`#000000`), Eye-Care Sepia (`#FBF0D9`), and Clean Modern Light (`#F8FAFC`) reading themes.
   - Minimum 48px touch ergonomic hitboxes, Amiri Arabic typography (`Amiri` font, RTL, 1.35em), and LocalStorage Bookmarks drawer.
   - Procedural Web Audio API feedback (tactile clicks & chimes) under strict Zero-Music Jurisprudence.
2. **Modern Word Mode 15 & Sub-Pixel Publishing**:
   - Compiles directly to native Microsoft Word 2013–365 OpenXML (`w:compatSetting w:val="15"`), eliminating legacy compatibility modes and enabling sub-pixel font rendering.
   - Standardized on Palatino Linotype ($10.5\text{ pt}$–$12.0\text{ pt}$) with lining figures ($0$–$9$) sitting on an even baseline.
3. **Sacred Arabic Script & Compact Honorifics**:
   - Quranic verses and Hadiths rendered in **Traditional Arabic Bold** ($15.0\text{ pt}$–$16.5\text{ pt}$) with $1.35\times$ line leading in Sacred Emerald Green (`#0F5132`).
   - Authentic Arabic honorifics (`رَضِیَ اللہُ عَنْہُ`, `رَحْمَةُ اللہِ عَلَيْہِ`) rendered compactly at **11.5pt Navy (`#1B365D`)** without `<w:rtl>` to eliminate bidi line flips and dotted circle artifacts.
   - 100% of Prophet citations standardized to **`Rasoolullah ﷺ`** using the authentic Unicode ligature (`\uFDFA`).
4. **Dynamic Document TOC with Real Page Numbers & Hyperlinks**:
   - Table of Contents entries link directly to chapter bookmark anchors (`<w:hyperlink>`) and feature exact, real physical document page numbers calculated via Microsoft Word COM automation.
